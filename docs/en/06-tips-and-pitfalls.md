# Tips and pitfalls

[繁體中文](../zh-TW/06-tips-and-pitfalls.md) · [Home](../../README.md)

These are narrow observations from the recorded setups. Commands that change a boot path or system volume need a separate backup and model-specific verification.

- **Tested:** An OCLP CLI build without installation produced a temporary build directory that disappeared when the process exited. In one experiment the process was paused after its “has been built at” log line, the EFI was copied, then the process continued. This is a fragile workaround, **not a supported build-only interface**. Validate the copied EFI with the matching OpenCore `ocvalidate` before testing it. [OCLP source](https://github.com/dortania/OpenCore-Legacy-Patcher), [OpenCore](https://github.com/acidanthera/OpenCorePkg).
- **Tested:** On iMac17,1 #1, the unpatched GCN GPU could not render the first Tahoe Setup Assistant screen. A machine-specific first-boot helper staged from the other macOS installation created a temporary administrator and enabled SSH; after that, installing `AutoPkg-Assets.pkg` triggered its postinstall root patch, and the patched Tahoe display became usable. The helper contained a temporary password and SSH key, so it is **not included as a reusable public script**. Reproduce only after reviewing target APFS volume roles, account security and recovery. [Apple APFS security](https://support.apple.com/en-asia/guide/security/seca6147599e/web), [OCLP assets release](https://github.com/dortania/OpenCore-Legacy-Patcher/releases/tag/3.0.0-rc.3).
- **Tested:** The iMac19,1's OCLP rebuild reinstated its hanging 5K diagnostics path and removed a locally added AMFIPass kext; a later rebuild could also replace the separately installed OpenCore 1.0.9. Inspect the new EFI **before rebooting** and reapply only the locally required changes. AMFIPass and SIP settings were specific to that audio patch on this setup. [AMFIPass](https://github.com/dortania/OpenCore-Legacy-Patcher/tree/main/payloads/Kexts/Acidanthera).
- **Tested:** A `Persist/*.tracev3` fragment in Preboot held only early boot evidence. Decoding needed a valid log archive with matching timesync and `uuidtext` data, plus `OSArchiveVersion=4`; incomplete archives can be misleading. Use `/usr/bin/log show --archive ...` where the shell's own `log` command would shadow the executable. A verbose boot photo was more decisive for the laptop's `RSRHelper` line. [Apple Unified Logging](https://developer.apple.com/documentation/os/logging).
- **Tested shell pitfalls:** With Bash 3.2 and `set -e`, a function ending in a false `condition && action` can make the script exit silently; return success explicitly where appropriate. Under `LC_ALL=C`, write `${VAR}` before non-ASCII text. On macOS, `plutil -replace` on an array index can insert rather than replace; inspect the resulting plist. `chmod -a "<ACE>"` subtracts the listed permissions from matching entries, so removing Time Machine's `deny write,delete,…` entries also strips the standard `group:everyone deny delete` protection on home folders; restore it afterwards (or copy with `ditto --noacl` and re-add only the standard entries). Check which `rsync` variant and flags are installed before relying on remote-copy behavior. These are observations, not a substitute for testing the exact shell and OS version.

- **Tested (iMac17,1 #2):** Copying OCLP's `AutoPkg-Assets.pkg` (taken from the release's install media) into `Library/Packages` on a `createinstallmedia` USB made the new system patch itself: around the first boot it had OCLP 3.0.0-rc.3 in `/Applications`, a patch record in `/System/Library/CoreServices/OpenCore-Legacy-Patcher.plist`, an auto-patcher log ending in "Patching complete", and accelerated 5K graphics, without a manual `installer -pkg`. A side effect: the system volume reports `Sealed: Broken`. A tool that treats "sealed" as "installation finished" must also accept an OCLP patch record. The install partition had only about 1 GB free after adding the 888 MB package, so check space first. [OCLP RC3 assets](https://github.com/dortania/OpenCore-Legacy-Patcher/releases/tag/3.0.0-rc.3).
- **Tested:** A helper that writes `.AppleSetupDone` after Setup Assistant has already started leaves Setup Assistant on screen (country selection) even though the account and the flag are correct. One more reboot goes to the login window.
- **Tested:** `brew update` fails on a restored system with "No developer tools installed" because Command Line Tools live under `/Library/Developer/CommandLineTools`, outside the home folder and `/usr/local`. Install them separately with `xcode-select --install` (needs network; this is not the multi-gigabyte Xcode app).
